# QR Editor — PRD Release 0

Основа: v0.1 от 15.10.2026. Актуальная редакция: 16.10.2026.
Границы согласованы [продуктовым брифом](./qr-studio-final-product-brief-ru-v1.4.md);
UX-компоновка и ограничения читаемости требуют проверки. Это целевые требования, не отчёт о готовом UI.

## Сценарий и приоритеты

Посетитель без регистрации вводит URL/текст → сразу видит QR → выбирает дизайн или
настраивает детали → получает понятные предупреждения → скачивает SVG/PNG.
Первый экран показывает содержимое, preview и стили; технические параметры скрыты
в смысловых группах. Отдельной обязательной кнопки генерации нет.

| Приоритет | Объём |
|---|---|
| P0 — Release 0 | URL/Text, live preview, пресеты и визуальные настройки, диагностика, SVG/PNG без водяного знака, мобильный путь |
| P1 — отдельное решение | Wi-Fi/vCard; локальное сохранение/повторное открытие и/или JSON дизайн-проекта |
| Release 1 | Аккаунты, динамические QR и Analytics Lite |
| После MVP | Brand Kit, пользовательские шаблоны, произвольный холст, массовая генерация, PDF/EPS, оплата |

Все реализованные функции редактора бесплатны. Ориентир 8–12 качественных пресетов
не требует реализовать столько вариантов до проверки качества и объёма работ.

## Требования P0

| Область | Поведение |
|---|---|
| Содержимое | Отдельные понятные формы URL и текста; Unicode и переносы; live update. Изменение оформления не меняет payload. Статический код не выдаётся за сменяемую ссылку. |
| Ошибки | Пустой ввод, переполнение и неверные параметры объясняются рядом с настройкой; ошибочное состояние не оставляет старый preview и доступный экспорт. Engine отдаёт коды, UI выбирает язык RU/EN или свой словарь. |
| Пресеты | Готовый дизайн доступен до детальных настроек. Каталог передаётся извне; выбор стиля не меняет содержимое и параметры кодирования. |
| Формы и цвета | Квадратные/скруглённые/круглые модули; отдельные кольца и центры маркеров; непрозрачные цвета, базовый линейный градиент, QR-фон и внешний фон. |
| Компоновка | Квадратная/круглая общая форма без обрезки матрицы и quiet zone; простая рамка; независимые верхняя/нижняя подписи, включая дуги у круга. Дуги не уменьшают QR. Произвольного холста нет. |
| Логотип | Растровый логотип с ограничениями формата, размера и пересечения служебных зон. ECC не трактуется как процент разрешённой площади. |
| Диагностика | Контраст, quiet zone, размер модуля, логотип и риск стилизации; предупреждения во время настройки с понятным действием для исправления. |
| Экспорт | Один SVG для preview и векторного файла; PNG из того же SVG в браузере. Полный применённый дизайн и прозрачность сохраняются, ошибки экспорта понятны. |
| Мобильный UX | Путь ввода/настройки/скачивания доступен без точных drag-жестов; preview легко доступен при работе с панелями. |
| Приватность | Генерация и экспорт локальные; payload и логотип не попадают в продуктовую аналитику. |

Пороги контраста, размеры для печати, политика ECC и допустимые сочетания стилей выбираются
после испытаний. Decode-тест снижает риск, но не гарантирует считывание на любом устройстве.

## Граница реализации

Форма и payload builder → строка → headless encoder → матрица → headless SVG Renderer.
Vue editor владеет формами, состоянием, выбором дизайна, показом диагностики и браузерным экспортом.
Engine не импортирует Vue/DOM и не содержит контролов. Общий editor переиспользуется в Astro и SPA.
Сохранение проекта P1 потребует версии формата с содержимым, кодированием, оформлением и ассетами.

Технический engine и playground уже есть: реализованы настройки из таблицы, SVG/PNG-путь и
RU/EN-каталоги. Playground — средство ручной проверки, не готовый публичный Vue editor.
Подробности API — в [README toolkit](../packages/qr-toolkit/README.md),
текущее состояние и пределы проверок — в [README документации](./README.md).

## Приёмка Release 0

1. Новый посетитель создаёт URL QR без регистрации и обучения; изменения видны без повторного нажатия «Создать».
2. Unicode и многострочный текст декодируются в исходный payload.
3. Пресет можно применить и изменить; содержание и кодирование остаются прежними.
4. Ошибки и рискованные параметры объясняются до экспорта; подсказка не обещает гарантии считывания.
5. SVG/PNG совпадают с preview и декодируются на утверждённой тестовой матрице; ошибки генерации не оставляют устаревший результат готовым к скачиванию.
6. Основной сценарий проверен на мобильном экране, экспорт — независимым декодером и целевыми телефонами. Рекомендации для печати требуют физического образца.
7. Нет регистрации, динамических маршрутов и биллинга; минимальные продуктовые события не содержат пользовательский контент.

## Открытые решения

- Целевые устройства, тестовые комбинации, пороги читаемости и допустимые размеры экспорта.
- Компоновка Vue-компонента, поля URL-валидации и группировка настроек.
- Состав финальной подборки пресетов; шесть текущих дизайнов являются демонстрационными.
- Включать ли P1 до первого публичного релиза; правила Wi-Fi/vCard и формат сохранения, если включаем.

Конкурентные наблюдения и частичный live-аудит хранятся только в
[Competitive & UX Research](./qr-studio-competitive-ux-research-2026-10-14.md); они не заменяют приёмку нашего редактора.
