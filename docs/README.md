## Текущее состояние

- Работает `packages/qr-toolkit`: headless encoder-адаптер над `qr@0.7.2`, собственный SVG Renderer, диагностика, словари ошибок RU/EN.
- Playground на HTML/CSS/TypeScript даёт ручную настройку, шесть демонстрационных дизайнов, SVG/PNG-экспорт и проверку через `BarcodeDetector`, если API доступен.
- Пресеты передаются извне; engine не содержит каталога и не зависит от Vue, DOM или языка интерфейса.
- Инициализирован `apps/frontend`: Vue/Vite/Nuxt UI, общая тема Iris в `packages/theme`, source-first `/ui` toolkit с Vue editor URL/Text: независимые черновики, live preview, базовые формы/цвета, диагностика и RU/EN. Запуск: `pnpm dev` из корня. Экспорт и полный набор визуальных контролов ещё не подключены.
- Astro/AdonisJS, сохранение проектов, динамические маршруты и аналитика ещё не реализованы. `docker-compose.yml` пока пустая заготовка.

## Проверки и ближайшая работа

Быстрые автотесты покрывают матрицы версий 1–40, SVG-геометрию, ограничения,
диагностику и локализацию. Отдельный `test:scan` проверяет реальный SVG/PNG в headless Chromium
независимым ZXing WASM decoder: все демо-пресеты, Unicode/emoji/переносы, размеры, ECC,
выбранные версии и формы маркеров, логотип, фиксированные искажения. Сценарии воспроизводимы,
результаты и проблемные файлы сохраняются; команды и условия — в README toolkit.

Ранее, 15.10, шесть PNG также прошли ручной прогон через `qr/decode.js` (версия 3, ECC Q, 512 px).
Новые тесты добавляют независимое декодирование; телефоны и физическая печать ещё не проверены.

Дальше — уточнять ограничения по результатам автоматических проверок и проектировать
Vue editor для Release 0: дальше экспорт SVG/PNG, затем пресеты и остальные настройки. Ручные испытания устройств/печати остаются перед публичным
релизом; автоматизация не считается их заменой. Новые декоративные возможности сейчас не приоритет.

`pnpm test:ui` проверяет реальные действия в Vue editor на desktop/mobile, включая ошибки
и отсутствие внешних запросов.

Запуск и команды проверок находятся в [README toolkit](../packages/qr-toolkit/README.md).
Исследования сохраняют дату исходного среза: внешние цены и функции в этой редакции заново не проверялись.
