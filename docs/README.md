## Текущее состояние

- Работает `packages/qr-toolkit`: headless encoder-адаптер над `qr@0.7.2`, собственный SVG Renderer, диагностика, словари ошибок RU/EN.
- Playground на HTML/CSS/TypeScript даёт ручную настройку, шесть демонстрационных дизайнов, SVG/PNG-экспорт и проверку через `BarcodeDetector`, если API доступен.
- Пресеты передаются извне; engine не содержит каталога и не зависит от Vue, DOM или языка интерфейса.
- Приложения Astro/Vue/AdonisJS, Vue editor, сохранение проектов, динамические маршруты и аналитика ещё не реализованы. `docker-compose.yml` пока пустая заготовка.

## Проверки и ближайшая работа

Автотесты покрывают матрицы версий 1–40, round-trip через decoder пакета `qr`, SVG-геометрию,
ограничения, диагностику и локализацию. В ручном прогоне 15.10 шесть экспортированных браузером
PNG декодированы через `qr/decode.js` с исходным URL (версия 3, ECC Q, ширина 512 px).
Это не независимый декодер и не проверка телефонами или печатью.

Ближайший этап — проверить экспорт независимым декодером и на целевых устройствах,
уточнить ограничения читаемости, затем спроектировать отдельный Vue editor и собрать Release 0.
Новые декоративные возможности сейчас не приоритет. Неопределённые пороги, мобильная
производительность и формат сохранения перечислены в техническом плане.

Запуск и команды проверок находятся в [README toolkit](../packages/qr-toolkit/README.md).
Исследования сохраняют дату исходного среза: внешние цены и функции в этой редакции заново не проверялись.
