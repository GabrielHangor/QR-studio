## Начало работы

- Создайте локальную папку/репозиторий `qr-studio` и распакуйте сюда файлы.
- Откройте эту папку как проект в Codex desktop.
- Попросите Codex сначала прочитать `AGENTS.md` и основной бриф, **не писать код без согласования задачи**.
- Подтверждённые решения отличать от гипотез, а будущие коммерческие сценарии не встраивать в бесплатный MVP.
