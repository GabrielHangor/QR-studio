## Границы и архитектура

- Release 0: бесплатный статический URL/Text editor без регистрации. Release 1: аккаунты, динамические QR и Analytics Lite, тоже без оплаты.
- Биллинг, тарифные механики, custom domains, Brand Kit, команды, массовая генерация и сложная аналитика — после MVP и отдельного решения.
- Стек: pnpm Workspaces; Astro + Vue для landing, Vue SPA для кабинета, AdonisJS + PostgreSQL для backend. Эти приложения пока не реализованы.
- Корень без зависимостей; инструменты и зависимости принадлежат использующим их пакетам. В toolkit — TypeScript, Vite, Vitest, Oxlint и Oxfmt.
- `@qr-studio/toolkit/engine`: `qr@0.7.2` от Paul Miller и собственный SVG Renderer, без Vue/DOM/контролов. PNG формируется в браузерном слое из того же SVG.
- Пресеты принадлежат вызывающему приложению. Ошибки и диагностика — `code + params`, словарь RU/EN выбирает интерфейс.
- Статический payload и логотип обрабатываются локально. Диагностика не гарантирует сканирование; нужны проверки файлов, устройств и печати.

## Работа с изменениями

Предпочитай небольшие проверяемые шаги. Не добавляй зависимости, сервисы и функции без необходимости.
Перед значительной задачей обозначь план и границы; после правок выполни релевантные проверки.
Не коммить секреты и реальные пользовательские данные. Факт, заявление конкурента и гипотеза — разные вещи.
При изменении решения обновляй его профильный документ, не дублируй описание во всём наборе.
