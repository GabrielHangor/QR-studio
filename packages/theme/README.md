# Общая тема QR Studio

Сдержанный синий, белые поверхности и холодный нейтральный фон.
Общая палитра применяется в редакторе, frontend и будущем лендинге.

- `@qr-studio/theme/tokens.css` — переносимые CSS-токены `--studio-*`: шкала синего,
  роли поверхностей, текста, границ и состояний. Не зависит от Vue/Nuxt UI/Tailwind;
  включает локальный Manrope. Это источник цветов для будущего Astro-приложения.
- `@qr-studio/theme/nuxt-ui.css` — адаптер ролей к Nuxt UI и шкалы `brand` к Tailwind.
- `@qr-studio/theme/nuxt-ui` — `studioTheme`: нейтральная палитра Slate, Remix Icons
  и общие варианты компонентов. Поля белые с обводкой; главный акцент задаётся явно.

Host импортирует `tailwindcss`, `@nuxt/ui`, затем `nuxt-ui.css` один раз.
Для интерфейса используй семантические роли, а не отдельные HEX в компонентах.
На лендинге можно менять долю акцентных/инвертированных поверхностей без отдельной палитры.
Цвета QR и каталог его дизайнов независимы от темы интерфейса.
Тёмные роли заданы через `.dark`; переключение режима принадлежит host.
